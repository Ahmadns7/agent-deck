Apply these web-development rules when relevant to the task:

- Do not add ARIA when a native element already has the semantics.
- Every interactive element needs an accessible name from text, aria-label, or aria-labelledby.
- Keep aria-expanded, aria-selected, and aria-pressed in sync with visual state.
- Test with a screen reader or the accessibility tree before shipping custom widgets.
