---
name: Color contrast and visual access
slug: a11y-color-contrast
category: accessibility
description: WCAG AA contrast, not relying on color alone, and text that scales.
---

Apply these web-development rules when relevant to the task:

- Body text needs at least 4.5:1 contrast; large text and UI boundaries need 3:1.
- Never use color as the only signal; pair it with text, icons, or shape.
- Use relative units (rem, em) so text scales with user settings.
- Check focus rings and disabled states against their backgrounds too.
