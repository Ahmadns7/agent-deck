name: Semantic HTML first
slug: a11y-semantic-html
category: accessibility
description: Use native elements before ARIA, with landmarks, heading order, and correct lists.
---

Apply these web-development rules when relevant to the task:

- Use button for actions and a for navigation; never a div with an onClick and no role.
- Use one h1 per page and do not skip heading levels.
- Wrap page regions in header, nav, main, and footer landmarks.
- Use ul, ol, and dl for lists and tables for tabular data only.
