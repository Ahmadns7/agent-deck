name: Architecture decision records
slug: arch-adr
category: architecture
description: Record decisions with context, the choice, and consequences so they can be revisited.
---

Apply these web-development rules when relevant to the task:

- Write a short ADR for each significant decision: context, decision, alternatives, consequences.
- Number ADRs sequentially and never delete one; supersede it with a new record.
- Keep ADRs in the repo under docs/adr/.
- Link the ADR from the code or PR that implements it.
