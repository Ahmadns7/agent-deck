Apply these web-development rules when relevant to the task:

- Use grid for two-dimensional layout and flex for one-dimensional rows or stacks.
- Set min-width: 0 on flex or grid children that contain long text or wide content.
- Use gap instead of margins between siblings.
- Prefer min(), max(), and auto tracks over fixed pixel widths.
