---
name: CSS theming and design tokens
slug: css-theming
category: css
description: Design tokens as CSS custom properties, light and dark themes, and color-scheme.
---

Apply these web-development rules when relevant to the task:

- Define color, spacing, and radius tokens as CSS custom properties on :root.
- Override tokens under a theme attribute or prefers-color-scheme; do not duplicate components per theme.
- Set color-scheme so native controls match the theme.
- Name tokens by role (surface, text-muted), not by value (gray-200).
