name: React forms
slug: react-forms
category: react
description: Controlled and uncontrolled inputs, validation timing, accessible errors, and submit states.
---

Apply these web-development rules when relevant to the task:

- Use native form elements and a real submit handler; disable the submit button only while submitting.
- Validate on blur or submit, not on every keystroke, and show errors next to the field.
- Associate error text with inputs using aria-describedby and set aria-invalid.
- Handle pending, success, and failure states explicitly.
