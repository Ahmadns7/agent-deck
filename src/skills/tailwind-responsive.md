description: Mobile-first breakpoints, container queries, and fluid sizing with clamp().
---

Apply these web-development rules when relevant to the task:

- Write base styles for mobile, then add md: and lg: overrides.
- Use container queries (@container) for components that appear in different-width slots.
- Use clamp() for fluid type and spacing instead of many breakpoints.
- Test at 320px, 768px, and 1280px widths before calling layout done.
