---
name: Test-driven development
slug: test-tdd
category: testing
description: Red, green, refactor: write the failing test first and keep each step minimal.
---

Apply these web-development rules when relevant to the task:

- Write one failing test that describes the next behavior and run it to see it fail.
- Write the smallest code that makes it pass, even if it is ugly.
- Refactor with the tests green, then move to the next behavior.
- Do not write production code without a failing test that requires it.
